# transformation-core/src/test/java/hu/blackbelt/judo/zeta/transformation/core — agent notes

The transformation engine's regression net. Nearly everything here transforms ECore→ECore (`EPackage`/`EClass`/`EAttribute`/`EReference`) so the engine is exercised without any JUDO metamodel on the classpath. Many files are named for a specific production bug in `judo-tatami` (esm2ui orphan `ActionDefinition`s, `RelationFeatureView` id mismatch, parallel element-count drift) and encode ETL-vs-Zeta semantic decisions — treat a failure here as a semantics change, not a flaky test, and never relax an assertion to make a build pass.

Two shared fixtures live in this directory rather than a `fixtures/` package: `AbstractEcoreTransformationTest` (base class) and `RealisticEcoreModelGenerator` (model generator). Neither is a test.
