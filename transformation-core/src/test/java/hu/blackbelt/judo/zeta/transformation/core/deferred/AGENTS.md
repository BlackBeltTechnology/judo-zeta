| `DeferredWritesTest.java` | Pins the deferred-EMF-write layer (`OperationQueue`, `EMFOperation`, `DeferredEObject`, `DeferredEList`) that keeps parallel rule bodies off EMF's non-thread-safe write path. Six `@Nested` groups: `OperationQueueTests` (sequence assignment, `add` applying immediately when deferred mode is OFF, sequence-ordered `commit`, `clear`/`reset`), `EMFOperationTests` (each sealed record's `apply()` against a real EMF object), `DeferredEObjectTests` (setter interception, read-after-write on pending single-valued features, passthrough methods, `unwrap`/`applyPendingValues`), `DeferredEListTests` (queued `add`/`remove`/`clear`, reads combining delegate plus pending additions minus pending removals), `IntegrationTests` (proxy + queue + commit end to end), `ConcurrentTests` (multi-threaded writes replaying deterministically after commit). Package-private JUnit 5 class with `@BeforeEach` fixture, 1061 lines. The concurrent group is the load-bearing one: it is what proves sequence-ordered replay is deterministic, so weakening it hides real parallel-transformation races. |
