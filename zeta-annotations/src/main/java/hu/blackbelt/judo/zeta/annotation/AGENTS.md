# zeta-annotations/src/main/java/hu/blackbelt/judo/zeta/annotation — agent notes

The whole public declaration surface of Zeta. Every annotation here is `RetentionPolicy.RUNTIME` — the registries in `validation-core` and `transformation-core` read them reflectively at `register(...)` time, so retention or target changes here break rule discovery estate-wide. Nothing here has behaviour; behaviour lives in the executors.

| File | Purpose |
|---|---|
| `Abstract.java` | Marks transform rule abstract — rule never runs on its own, only when a child rule calls `executeParentRule()`. No elements. `@Target(METHOD)`. Pair with `@Extends` on the child; an `@Abstract` rule with no child that extends it is dead code the executor never invokes. |
| `ActivityBased.java` | Restricts a `@Greedy @Lazy` rule to elements activated by an `equivalent()` call, reproducing Epsilon ETL's implicit `@greedy @lazy` filtering. No elements. `@Target(METHOD)`. Requires both `@Greedy` and `@Lazy` present — alone it does nothing and rule registration emits a warning. Activated elements are processed in a second phase after eager execution, so eager rules cannot observe their targets. Blanket alternative: `TransformationExecutor.builder().etlCompatibilityMode(true)`. |
| `Cached.java` | Memoises an `@ExtensionMethod` method result, EOL's `@cached` operation annotation. No elements. `@Target(METHOD)`. Cache key derives from `self` plus arguments: `EObject` → XMI id (`Resource` id or `EcoreUtil.getURI`), primitives/`String`/`Number`/`Boolean`/`Enum` → value, `Collection` → ordered element keys, `Map` → entries sorted by key. Order-sensitive collections therefore key differently after a reorder, and mutating a cached argument after the call invalidates nothing. |
| `Constraint.java` | Declares an error-severity validation rule; violations block model processing. Exports `name()` (required, must be unique — `@Satisfies` resolves dependencies by this name), `description()` `""`, `message()` `""`, `resourceAlias()` `"source"`. `@Target(METHOD)`. Annotated method returns the `ValidationRule` lambda, not the verdict. |
| `Critique.java` | Declares a warning-severity validation rule; violations are reported but do not block processing. Exports `name()` (required, unique), `description()` `""`, `message()` `""`, `resourceAlias()` `"source"`. `@Target(METHOD)`. Same shape as `@Constraint` — only the emitted `Severity` differs. |
| `Detached.java` | Marks a `@Lazy` rule whose target is NOT appended to `Resource.contents`, matching ETL's lazy-rule semantics for objects that only make sense inside a parent (`Action` inside `PageDefinition.actions`). No elements. `@Target(METHOD)`, `@Documented`. Caller of `equivalent(...)`/`equivalentDiscriminated(...)` must add the result to its container or the object is orphaned and silently lost on serialisation. |
| `Extends.java` | Declares rule inheritance. Exports `String[] value()` — names of parent rules the annotated rule extends, invoked via `executeParentRule()` in the transformation context. `@Target(METHOD)`. Names must match a registered `@TransformRule(name = ...)`; typos fail at execution, not registration. |
| `ExtensionMethod.java` | Class-level marker binding a helper class to one EClass type, the Java stand-in for EOL operations. Exports `Class<? extends EObject> value()` — the type extended. `@Target(TYPE)`. Methods in the class take that type as first parameter (`self`); combine with `@Cached` on expensive traversals. |
| `Greedy.java` | Switches rule matching from type-of (exact, the default) to kind-of (subtype-inclusive), mirroring Epsilon ETL's `@greedy`. No elements. `@Target(METHOD)`. Read by `TransformRuleDescriptor.appliesTo(EObject)`. Adding `@Greedy` widens the matched element set, so a subtype previously handled by its own rule can now be double-matched. |
| `Guard.java` | Names a predicate method that short-circuits a validation or transformation rule; false skips the rule for that element. Exports `String method()` — the guard method name. `@Target(METHOD)`. Guard method must live in the SAME class and be resolvable by name; validation guards take `(EObject, ValidationContext)`, transformation guards take the source element. Applies equally to `@Constraint`/`@Critique` and `@TransformRule`. |
| `Lazy.java` | Marks a transform rule lazy — skipped in the eager phase, executed only when an `equivalent()` call demands its target. No elements. `@Target(METHOD)`. A lazy rule nobody calls `equivalent()` for never runs and produces no target. |
| `PostExecution.java` | Marks a teardown hook invoked once after all validation or transformation rules have run. No elements. `@Target(METHOD)`. Method takes the run's `ValidationContext` or `TransformationContext`; used to drain `ctx.getAttribute(...)` state set up in `@PreExecution` (cache clear, statistics logging). Runs after the last rule, so results are already final. |
| `PreExecution.java` | Marks a setup hook invoked once before any validation or transformation rule runs. No elements. `@Target(METHOD)`. Method takes the run's `ValidationContext` or `TransformationContext`; typical body is `ctx.setAttribute("cache", new HashMap<>())`. State it seeds must be torn down by a matching `@PostExecution` or it leaks across runs sharing the context. |
| `Primary.java` | **Deprecated.** Formerly marked a transform rule primary for implicit rule selection. No elements. `@Target(METHOD)`, `@Deprecated`. Framework no longer reads it — presence has zero effect. Replace with explicit `equivalent(source, "RuleName")` selection; slated for removal. |
| `Satisfies.java` | Declares that a `@Constraint`/`@Critique` depends on other named rules passing first, so execution order is derived rather than hand-sequenced. Exports `String[] value()` — dependency rule names. `@Target(METHOD)`. Names must match declared `@Constraint`/`@Critique` `name()` values; a dependency cycle is unsatisfiable. |
| `To.java` | Declares one target type of a transform rule plus the aliased resource it is created in. Exports `alias()` default `"target"`, `Class<? extends EObject> type()` (required). `@Target(METHOD)`, `@Repeatable(Tos.class)`. `ctx.create(Type.class)` looks the alias up from the `@To` whose `type` matches, so a `create` of a type with no `@To` has no resource to land in. Duplicate alias+type pairs are allowed and declarative. |
| `Tos.java` | Container annotation the compiler synthesises when a method carries multiple `@To`. Exports `To[] value()`. `@Target(METHOD)`, `RUNTIME`. Never written by hand; declared solely so `@Repeatable(Tos.class)` on `To` is legal. Registry reading `@To` reflectively must handle both the single and the `Tos`-wrapped form. |
| `Transform.java` | Declares one source type of a transform rule plus the aliased resource it is read from. Exports `alias()` default `"source"`, `Class<? extends EObject> type()` (required). `@Target(METHOD)`, `@Repeatable(Transforms.class)`. Multiple `@Transform` annotations make the rule receive a Cartesian product of the source types — the function signature must then be `TransformFunction<Object[], …>`, not a single-source one. |
| `TransformRule.java` | Declares a transformation rule method. Exports `name()` (required, unique — `@Extends` and `equivalent(source, name)` resolve by it), `description()` `""`, `sourceTypes()` `{}`, `targetTypes()` `{}`. `@Target(METHOD)`. Non-empty `sourceTypes`/`targetTypes` OVERRIDE the `source()`/`target()` declared by the enclosing `@TransformationContext`. |
| `TransformationContext.java` | Class-level marker declaring a holder of transformation rules and its default source/target types. Exports `Class<? extends EObject> source()`, `Class<? extends EObject> target()` — both required. `@Target(TYPE)`. Supplies defaults only; any `@TransformRule` on the class that sets `sourceTypes`/`targetTypes` overrides them. Distinct from the runtime `TransformationContext` class the rule bodies receive. |
| `Transforms.java` | Container annotation the compiler synthesises when a method carries multiple `@Transform`. Exports `Transform[] value()`. `@Target(METHOD)`, `RUNTIME`. Never written by hand; exists so `@Repeatable(Transforms.class)` on `Transform` is legal. Reflective readers must unwrap it as well as the single form. |
| `ValidationContext.java` | Class-level marker declaring a holder of validation rules and the EClass type they apply to. Exports `Class<? extends EObject> value()` — required. `@Target(TYPE)`. A class registered into a `ValidationRegistry` without this annotation contributes no rules; the declared type is what `ValidationExecutor` matches walked elements against. Distinct from the runtime `ValidationContext` class passed into rule bodies. |
